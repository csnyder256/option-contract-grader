# option-contract-grader v0.2.1 — Deployable local screener

## What changed

- Local Docker Compose deployment with persistent SQLite data.
- Audited scoring, feed handling and boundary regression fixes.
- Release metadata now matches the API version.

## Install and upgrade

Back up the SQLite database before upgrading. Supply feed credentials at runtime if required. The default endpoint is for a single local user; it has no public authentication layer.

See [deployment instructions](../../DEPLOYMENT.md) and the attached checksums.
