# Scenario simulator and transparent grade reports — v0.3.0

Explore spot moves, implied volatility and elapsed time for a hypothetical long call or put. The simulator shows theoretical option marks and expiry payoff, fees, long-position loss limits and breakeven. The grade trace exposes component weights, contributions, thresholds, assumptions and the illiquidity cap.

Export the scenario and its grade as JSON, formula-safe CSV or standalone HTML with input and code fingerprints. Scenarios require no quote provider or trading account and place no orders. Theoretical prices and risk-neutral statistics are model outputs, not a prediction of returns. The current grading weights are unchanged.

## Install and upgrade

Use the versioned [deployment instructions](https://github.com/csnyder256/option-contract-grader/blob/v0.3.0/DEPLOYMENT.md) and verify the release checksums before upgrading. Preserve existing user data and policy configuration.
